# Image Asset Manifest — Isaiah Ball Homepage

Imported 2026-08-17 from Isaiah's Drive folder ("Pics for Website"), reviewed directly (not inferred from filenames) before selection. Originals preserved at full resolution/quality — no compression or downscaling applied. One HEIC file was converted to JPEG (format only, same pixel dimensions, no quality loss) since HEIC has inconsistent browser support.

**Repo-size note:** this folder is ~123MB across 19 images (originals range 900KB-17MB). That's a real weight to carry in git history for a marketing site. Kept as-is per explicit instruction to preserve original quality, but flagging for implementation: Next.js's built-in Image component will handle responsive resizing/format conversion at build/serve time from these sources, which is the intended use — but if repo size becomes a problem (slow clones, CI cache bloat), consider git-lfs or moving originals to an external asset host before launch. Not resolved here; a launch-readiness item, not blocking planning.
